
# 📚 Sistema de Cadastro e Vendas de Livros

Sistema web desenvolvido em **Python e Django**, com o objetivo de gerenciar o cadastro, a organização e a comercialização de livros por meio de uma plataforma intuitiva e funcional.

> 🚧 **Status: Em desenvolvimento**

## 📌 Sobre o Projeto

O **Sistema de Cadastro e Vendas de Livros** é uma aplicação web desenvolvida utilizando o framework Django.

O projeto tem como proposta criar uma plataforma para gerenciamento de livros, permitindo organizar informações, administrar cadastros e desenvolver funcionalidades relacionadas à comercialização de produtos.

Além de sua finalidade prática, o sistema é desenvolvido para aprimorar conhecimentos em desenvolvimento backend, bancos de dados, autenticação e arquitetura de aplicações web.

## 🎯 Objetivos do Projeto

- Desenvolver uma aplicação web utilizando Python e Django.
- Implementar o gerenciamento de livros.
- Criar funcionalidades relacionadas à venda de livros.
- Trabalhar com autenticação e gerenciamento de usuários.
- Aplicar operações CRUD (Create, Read, Update e Delete).
- Organizar e armazenar informações em banco de dados.
- Construir uma interface intuitiva e responsiva.
- Aplicar boas práticas de desenvolvimento web.

## ⚙️ Instalação e Execução

### 1. Clone o repositório

```bash
git clone https://github.com/joaohschulz/Sistema-de-Cadastro-e-Vendas-de-Livros.git
```

### 2. Acesse o diretório do projeto

```bash
cd Sistema-de-Cadastro-e-Vendas-de-Livros
```

### 3. Crie um ambiente virtual

```bash
python -m venv .venv
```

### 4. Ative o ambiente virtual

**Windows:**

```bash
.venv\Scripts\activate
```

**Linux/macOS:**

```bash
source .venv/bin/activate
```

### 5. Instale as dependências

```bash
pip install -r requirements.txt
```

### 6. Configure o banco de dados

```bash
python manage.py migrate
```

### 7. Inicie o servidor

```bash
python manage.py runserver
```

Acesse pelo navegador:

```text
http://127.0.0.1:8000/
```

> Como o projeto ainda está em desenvolvimento, algumas funcionalidades podem não estar disponíveis ou apresentar alterações.
